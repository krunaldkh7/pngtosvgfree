How to use these free SVG files

Every illustration in this gallery is a hand-built vector file, so it stays perfectly sharp whether you print it on a sticker, cut it from vinyl or use it as a website icon. Click Download to save the .svg file, or Copy to put the SVG code on your clipboard and paste it straight into your HTML, Figma or Inkscape.

For cutting machines

Upload the downloaded file to Cricut Design Space or Silhouette Studio as you would any SVG. Shapes with several colours import as separate layers, which you can cut from different vinyl or cardstock colours. If you want a single-colour cut, weld or attach the layers before cutting.

For design tools and the web

Open the file in Figma, Illustrator, Inkscape or Canva to change colours, resize it or combine it with your own work. On a website you can use the file in an <img> tag or paste the code inline, then style it with CSS.

Changing colours

Each SVG uses plain fill colours, so recolouring is easy: select a shape in your design tool and pick a new fill, or edit the fill values in the code with any text editor.
