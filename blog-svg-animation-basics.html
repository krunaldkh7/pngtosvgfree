SVG Animation Basics: CSS, SMIL and JavaScript

Animated SVGs add life to websites: loading spinners, icons that react to clicks, logos that draw themselves on screen. Because SVG is made of real elements, each part can be animated independently, and the result stays sharp at any size while weighing far less than a GIF or video.

There are three main ways to animate SVG. This guide explains each, with small examples you can adapt.

Before you start: use inline SVG

To animate parts of an SVG with CSS or JavaScript from your page, the SVG must be inline in the HTML. SVGs loaded through <img> can still run animations defined inside the file itself, but your page's CSS and scripts cannot reach them.

1. CSS animation

CSS is the easiest and most common choice. Any SVG element can be animated with @keyframes, transitions and transforms.

A spinning loader

<svg class="spin" viewBox="0 0 50 50" width="40" height="40">
  <circle cx="25" cy="25" r="20" fill="none" stroke="#3d4ef5" stroke-width="5" stroke-dasharray="90 150" stroke-linecap="round"/>
</svg>

.spin { animation: rotate 1s linear infinite; }
@keyframes rotate { to { transform: rotate(360deg); } }

The "line drawing" effect

This popular effect makes an outline appear as if drawn by hand. It uses two stroke properties: stroke-dasharray creates a dash as long as the whole path, and stroke-dashoffset shifts it out of view, then back.

.draw path {
  stroke-dasharray: 1000;
  stroke-dashoffset: 1000;
  animation: draw 2s ease forwards;
}
@keyframes draw { to { stroke-dashoffset: 0; } }

Replace 1000 with the actual path length for precise timing; JavaScript's path.getTotalLength() tells you the value. Adding pathLength="1" to the path lets you use 1 instead, avoiding the measurement altogether.

Transform origin gotcha

By default, SVG elements rotate and scale around the SVG's top-left corner, not their own centre. Add transform-box: fill-box; transform-origin: center; to transform shapes around their own centre.

2. SMIL animation

SMIL is SVG's built-in animation syntax. Animations are written as elements inside the SVG file:

<circle cx="20" cy="20" r="8" fill="#ec4899">
  <animate attributeName="r" values="8;14;8" dur="1.5s" repeatCount="indefinite"/>
</circle>

SMIL's big advantage is that the animation lives inside the file, so it plays even when the SVG is used in an <img> tag. It can also animate things CSS cannot easily reach, such as moving an object along a path with <animateMotion> or morphing a path's shape. All modern browsers support it.

3. JavaScript animation

For interactive or complex sequences — animations that respond to scrolling, data or user input — JavaScript gives full control. The browser's Web Animations API works on SVG elements:

document.querySelector('#star').animate(
  [{ transform: 'scale(1)' }, { transform: 'scale(1.3)' }, { transform: 'scale(1)' }],
  { duration: 600, easing: 'ease-out' }
);

Libraries such as GSAP, anime.js and Motion make timelines, path morphing and scroll-linked animation easier, and smooth over browser differences.

Which method should you use?

SituationRecommended
Hover effects, loaders, simple loopsCSS
Animation must work inside <img> or be self-containedSMIL
Interactive, data-driven or long sequencesJavaScript

Performance tips

  • Animate transform and opacity when possible; they are cheaper for the browser than changing shapes or filters.
  • Keep path counts low. An animated traced image with thousands of shapes can stutter on phones — optimise first (see How to Reduce SVG File Size).
  • Avoid animating large blur filters, which are expensive to redraw.

Respect reduced-motion preferences

Some people experience discomfort from motion on screen. Wrap non-essential animation in a media query:

@media (prefers-reduced-motion: reduce) {
  .spin, .draw path { animation: none; }
}

Animating your own artwork

Have a logo only as a PNG? Convert it with our PNG to SVG converter, open the SVG in a code editor, give the paths you want to move a class or ID, and apply the techniques above. Simple, flat-colour logos with few paths are the easiest to animate.

Summary

CSS handles most SVG animation needs, SMIL keeps animation inside the file, and JavaScript unlocks interactivity. Start with simple transforms and stroke-drawing effects, keep files lean, and always provide a reduced-motion fallback.
