Why convert a GIF to SVG?

A GIF is a small raster image with at most 256 colours; an SVG is a vector that stays sharp at any size. Many old logos, website buttons and icons only survive as GIF files. Converting them to SVG lets you scale them for print, recolour them, cut them on a Cricut or laser, and use them on modern high-resolution screens without blur.

Does it work with animated GIFs?

No — SVG output is a still image, so only the first frame of an animated GIF is converted. If you need a different frame, save that frame as its own image first and upload it.

Tips for a clean GIF trace

  • Dithered GIFs (tiny checkerboard dots used to fake extra colours) produce speckles. Increase Speckle removal and lower the colour count.
  • Very small GIFs such as 32×32 icons have little detail to trace. Use the largest version of the GIF you can find.
  • Transparent GIFs keep a transparent background in the SVG — the clear areas simply have no shapes.
