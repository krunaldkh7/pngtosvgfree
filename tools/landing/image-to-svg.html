What does it mean to vectorize an image?

Vectorizing an image means converting its pixels into mathematical shapes — paths, curves and fills — so it can be resized to any size without losing quality. Photos and screenshots are raster images: fixed grids of coloured pixels. Vector images such as SVG describe what to draw rather than storing each pixel, which makes them ideal for logos, icons, illustrations, cutting machines and print.

How does automatic tracing work?

Automatic tracing reduces the image to a small palette, groups pixels into colour regions and fits smooth curves around each region. The converter first detects the image type, then quantizes colours, cleans up anti-aliasing halos and small specks, and finally traces each colour layer into Bézier paths with sharp-corner detection. When should you not vectorize an image?

Do not vectorize detailed photographs you only want to display on a website — a JPG, WEBP or AVIF will be smaller and look more realistic. Vectorize when you need infinite scaling, editable colours, cut paths or print-ready artwork.

Does the SVG contain my original pixels?

No, the SVG contains only vector paths traced from the image. No raster data is embedded, which keeps the file clean and editable.
