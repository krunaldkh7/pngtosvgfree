SVG is one of the most common graphic formats on the web, but double-clicking one does not always do what you expect. Sometimes it opens in a browser, sometimes in a text editor, and sometimes your phone says it cannot preview it. Here is how to open SVG files on every major platform — and how to edit them.

The universal method: any web browser

Every modern browser — Chrome, Edge, Firefox, Safari, Opera — can display SVG files. On a computer, drag the file into an open browser window, or right-click it and choose Open with and your browser. This works on Windows, macOS, Linux and ChromeOS, and it is the quickest way to check what an SVG looks like.

Windows

Viewing

  • Browser: right-click the file → Open with → Microsoft Edge or another browser.
  • File Explorer thumbnails: Windows does not always show SVG thumbnails by default. Free extensions such as the open-source "SVG Viewer Extension for Windows Explorer" add thumbnail previews.
  • Microsoft Office: Word, PowerPoint and Excel in Microsoft 365 can insert SVGs via Insert → Pictures.

Editing

Inkscape (free), Adobe Illustrator, Affinity Designer and CorelDRAW all edit SVG. For quick colour changes, see our guide to editing SVG files in Inkscape.

Mac

Viewing

  • Quick Look: select the file in Finder and press the Space bar for an instant preview.
  • Safari or any browser: drag the file in.
  • Preview app: recent versions of macOS can open SVGs in Preview; if yours cannot, use a browser.

Editing

Inkscape, Affinity Designer, Adobe Illustrator, Sketch and Figma (by dragging the file onto the canvas) all work on Mac.

iPhone and iPad

  • Files app: tap an SVG to preview it with Quick Look in most cases.
  • Safari: SVGs opened from a website display directly.
  • Editing: apps such as Affinity Designer for iPad, Vectornator/Linearity Curve and Canva can import SVGs. Cricut Design Space on iOS can upload SVGs from the Files app for cutting projects.

Android

  • Chrome: open the file from your downloads, or use a file manager and choose Chrome to open it.
  • Gallery apps: many do not support SVG; use a browser or a dedicated SVG viewer app instead.
  • Editing: Canva and some vector drawing apps accept SVG uploads.

Opening SVG as code

Because SVG is text (XML), you can open it in any text or code editor — Notepad, TextEdit (in plain-text mode), VS Code. This is useful for quick fixes such as changing a fill colour or checking the viewBox. Be careful not to break the XML structure; keep a copy of the original.

Converting SVG when an app will not open it

Some apps — certain social media platforms, older photo editors and many email clients — do not accept SVG. Convert it to a PNG at the size you need with our free Bulk SVG to PNG converter. You can keep a transparent background or add a white one.

Why does my SVG look wrong or blank?

  • Missing fonts: text in an SVG uses fonts from your computer. If the font is not installed, another is substituted. Ask for a version with text converted to outlines.
  • Linked images: an SVG can reference external image files. If those are missing, parts appear empty.
  • Very large or tiny artwork: the drawing may sit outside the visible area defined by the viewBox. See The SVG viewBox Explained.
  • The file is not really an SVG: sometimes a PNG or HTML page is saved with an .svg extension. Open it in a text editor; a real SVG starts with <svg or an XML declaration.

Is it safe to open SVG files?

SVGs can contain scripts. Viewing them as an image (for example in an <img> tag or Quick Look) does not run scripts, but opening an untrusted SVG directly in a browser tab can. Only open SVGs from sources you trust. Read more in Is SVG Safe? Security Risks Explained.

Summary

A web browser opens SVG on any computer. Use Quick Look on Mac and iPhone, a browser on Android, and a vector editor such as Inkscape when you need to make changes. When an app refuses SVG, convert it to PNG first.
