Open almost any SVG in a text editor and you will find long strings like d="M10 20 L50 20 C60 20 70 30 70 40 Z". This is path data, the heart of vector graphics. Every logo, icon and traced image is ultimately made of these commands. You do not need to write them by hand, but understanding them makes editing, debugging and optimising SVGs much easier.

How a path works

Imagine a pen on paper. Path commands tell the pen where to move and what to draw. Each command is a letter followed by numbers (coordinates). The y-axis points down: (0, 0) is the top-left corner.

Uppercase letters use absolute coordinates (positions in the drawing). Lowercase letters use relative coordinates (distances from the current pen position).

Moving and drawing lines

  • M x y — Move the pen without drawing. Every path starts with M.
  • L x y — draw a straight Line to a point.
  • H x — draw a Horizontal line to an x position.
  • V y — draw a Vertical line to a y position.
  • Z — close the path by drawing a line back to the start.
<path d="M10 10 H90 V90 H10 Z" fill="#3d4ef5"/>

This draws a square: start at (10,10), go right to x=90, down to y=90, left to x=10, then close.

Curves

Cubic Bézier: C

C x1 y1, x2 y2, x y

Draws a smooth curve to (x, y). The two control points (x1, y1) and (x2, y2) pull the curve towards them like magnets — the first shapes the start of the curve, the second shapes the end. This is the same type of curve you drag with handles in Illustrator, Figma or Inkscape, and it is the most common command in traced SVGs.

Smooth cubic: S

S x2 y2, x y continues a curve smoothly. Its first control point is automatically mirrored from the previous curve, so joins stay seamless.

Quadratic Bézier: Q and T

Q x1 y1, x y uses a single control point — simpler but less flexible. T x y continues it smoothly.

Arcs: A

A rx ry rotation large-arc-flag sweep-flag x y

Draws part of an ellipse with radii rx and ry to the point (x, y). The two flags (0 or 1) choose which of the four possible arcs is drawn — the large or small one, clockwise or anticlockwise. Arcs are great for rounded corners and pie charts but are the trickiest command to write by hand.

Reading a real example

M12 2 L15 9 H22 L16.5 13 L18.5 20 L12 16 L5.5 20 L7.5 13 L2 9 H9 Z

Start at the top (12, 2), draw lines around ten points and close the shape. The result is a five-pointed star — readable once you know the letters.

Holes inside shapes

A single path can contain several sub-paths, each starting with M. The letter "O" is typically one outer loop and one inner loop. The fill-rule property (nonzero or evenodd) decides whether the inner loop becomes a hole. Traced SVGs use this to cut counters out of letters and holes out of shapes.

Why path data gets long

Traced images describe organic shapes with many curve segments, and design tools often export coordinates with many decimal places. Both make the d attribute long. Techniques to shorten it — fewer nodes, lower precision, relative commands — are covered in How to Reduce SVG File Size.

Practical edits you can make by hand

  • Move a whole shape: wrap it in <g transform="translate(10,0)"> rather than changing every coordinate.
  • Change a colour: edit the fill attribute of the path, no path data needed.
  • Find a stray shape: delete paths one at a time (or set fill="red") to see which is which.
  • Close an open shape for cutting: add Z at the end of its path data.

Tools for exploring paths

Browser developer tools let you edit an inline SVG's path data and see the result instantly. Online path visualisers show each command and control point. And vector editors such as Inkscape include an XML editor that displays the path data as you move nodes.

Summary

M moves, L/H/V draw lines, C/S/Q/T draw curves, A draws arcs and Z closes. Uppercase means absolute, lowercase means relative. With those few rules, the cryptic d attribute becomes a readable set of drawing instructions you can inspect and adjust with confidence.
