Learn practical ways to shrink SVGs — from smarter tracing settings to removing editor metadata. ---

SVG is usually lightweight, but not always. An icon exported straight from a design tool can carry kilobytes of unnecessary metadata, and a traced image can contain thousands of tiny shapes. Smaller SVGs load faster, render faster and are easier to edit. Here are nine techniques, roughly ordered from biggest impact to smallest.

1. Use fewer colours when tracing

When an image is converted to SVG, every colour region becomes at least one path. Doubling the colour count can more than double the file size. For logos and icons, set the number of colours to exactly what the design needs. Our converter shows the size, number of paths and colours of the result, so you can see the effect of each change immediately.

2. Remove speckles and tiny shapes

Small islands of colour, often caused by JPG compression or noise, add paths without adding visible detail. Increasing speckle removal deletes them. In a vector editor, you can also select and delete tiny fragments manually.

3. Lower the detail level

Higher detail means more nodes along every curve. For artwork displayed at small sizes, such as icons, a lower detail setting produces smoother curves with far fewer points and no visible difference.

4. Simplify paths

Vector editors can reduce the number of nodes in a path while keeping its shape. In Inkscape use Path → Simplify (Ctrl+L); in Illustrator use Object → Path → Simplify. Apply gently — too much simplification distorts shapes.

5. Strip editor metadata

Design tools often embed extra information: editor namespaces, layer names, guides, comments and hidden objects. Inkscape offers an Optimized SVG save option, and Illustrator's export dialog lets you minimise output. The free tool SVGO (and its web interface SVGOMG) removes most of this automatically and is widely used in web projects.

6. Reduce decimal precision

Coordinates like 124.38291745 are far more precise than any screen needs. Rounding to one or two decimal places can cut file size significantly. SVGO does this with a precision setting; check the result visually, because too little precision can make small icons look misaligned.

7. Avoid embedded raster images

An SVG can contain a PNG or JPG encoded inside it as base64 text. This makes the file about a third larger than the image itself and removes the benefits of vector graphics. If your SVG contains an <image> element with a long data: string, consider tracing that image into true vectors or serving it separately.

8. Convert text to paths only when needed

Text converted to outlines guarantees the right appearance without the font installed, but every letter becomes a complex path. For website graphics where the font is available, keeping live text can be smaller. For logos and cutting files, outlines are usually the safer choice.

9. Compress for delivery

SVG is text, so it compresses extremely well. Web servers and CDNs can serve SVGs with gzip or Brotli compression, often reducing transfer size by 60–80%. Make sure your server or hosting includes image/svg+xml in its compressed content types.

What is a "good" SVG size?

Type of graphicTypical optimised size
Simple iconUnder 1–2 KB
Logo2–20 KB
Detailed illustration20–200 KB
Traced photographOften 200 KB or more

If a traced photo ends up larger than a high-quality JPG or WEBP of the same image, the raster format is probably the better choice for that use.

A quick optimisation workflow

  1. Trace with the minimum colours and a sensible detail level.
  2. Remove background shapes and stray fragments.
  3. Simplify paths lightly in a vector editor if needed.
  4. Run the file through SVGO or SVGOMG.
  5. Compare the optimised file with the original at 100% and 400% zoom.

Summary

Most SVG bloat comes from too many shapes and nodes, followed by editor metadata and excessive precision. Fix the first at the tracing stage, clean up the rest with an optimiser, and let your server compress the result. Your pages — and anyone editing the files later — will thank you.
