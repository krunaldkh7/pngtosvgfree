Inkscape is a free, open-source vector graphics editor for Windows, macOS and Linux. Unlike many design tools that merely import SVG, Inkscape uses SVG as its native format, which makes it an excellent choice for editing logos, icons, cutting files and traced images. This guide covers the tasks you will need most often.

Getting started

Download Inkscape from the official website, inkscape.org. Open your SVG with File → Open or by dragging it onto the window. The main tools are on the left toolbar; colour swatches run along the bottom; and panels such as Fill and Stroke and Layers and Objects open on the right.

Selecting objects

  • Selector tool (S): click an object to select it. Shift-click adds to the selection.
  • Groups: traced and exported SVGs often wrap shapes in groups. Double-click to enter a group, or use Object → Ungroup (Shift+Ctrl+G) to break it apart.
  • Select same colour: select one shape, then Edit → Select Same → Fill Color. This is invaluable for traced images where one colour may be spread across many shapes.

Changing colours

  1. Select the shapes you want to change.
  2. Click a swatch at the bottom of the window, or open Object → Fill and Stroke (Shift+Ctrl+F).
  3. On the Fill tab, choose flat colour and enter a hex code such as 3d4ef5ff (the last two digits are opacity).

Use the Stroke paint tab to add or remove outlines.

Deleting a background

Traced images may include a large background shape. Click it and press Delete. If it is hard to click, use Edit → Select Same → Fill Color after selecting a visible part, or find it in the Layers and Objects panel.

Resizing precisely

With an object selected, the toolbar at the top shows X, Y, W and H fields. Choose units (px, mm, in), lock the ratio and type the exact width. To make the document page fit your artwork, use Edit → Resize Page to Selection (Shift+Ctrl+R), or set a page size in File → Document Properties.

Cleaning up traced artwork

Simplify paths

Select shapes and press Ctrl+L (Path → Simplify) to reduce the number of nodes. Repeat for more smoothing, but watch that shapes do not distort.

Edit nodes

The Node tool (N) shows each point on a path. Drag nodes to reshape, select and press Delete to remove them, or use the toolbar to make corners sharp or smooth.

Combine and separate

  • Path → Union (Ctrl++) merges overlapping shapes into one — useful for cutting files.
  • Path → Difference (Ctrl+-) cuts the top shape out of the one beneath.
  • Path → Combine (Ctrl+K) joins shapes into one path; Path → Break Apart (Shift+Ctrl+K) splits them.

Working with text

Use the Text tool (T) to add text. Before sending a file to a printer, cutting machine or anyone who may not have the font, convert text to paths with Path → Object to Path (Shift+Ctrl+C).

Saving and exporting

  • Inkscape SVG keeps Inkscape-specific data such as layers and guides — best for continued editing.
  • Plain SVG removes Inkscape extras for broader compatibility.
  • Optimized SVG shrinks the file further for websites.
  • Export PNG: File → Export (Shift+Ctrl+E) lets you choose size and DPI.
  • PDF and EPS: available through File → Save As.

A typical workflow for a traced logo

  1. Convert your PNG or JPG with our PNG to SVG converter.
  2. Open the SVG in Inkscape and ungroup it.
  3. Delete the background and any stray fragments.
  4. Use Select Same → Fill Color to recolour each brand colour exactly.
  5. Simplify lightly and fix any shapes with the Node tool.
  6. Resize the page to the artwork and save as Plain SVG, plus a PDF if needed.

Summary

Inkscape gives you professional SVG editing for free. Learn to select by colour, change fills, delete backgrounds, simplify paths and resize the page, and you can handle the vast majority of real-world SVG edits in minutes.
