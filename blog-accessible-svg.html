How to Make SVG Graphics Accessible

SVGs are everywhere in modern interfaces — logos, icons, charts and illustrations. For people who use screen readers, voice control or high-contrast modes, poorly marked-up SVGs can be silent, confusing or invisible. The good news is that making SVG accessible takes only a few attributes.

Step 1: Decide whether the graphic is meaningful or decorative

Ask: if this image disappeared, would a user miss any information?

  • Meaningful — conveys information or performs an action: a logo linking home, a chart, an icon-only button, a diagram.
  • Decorative — purely visual: background shapes, ornaments, an icon that sits next to text which already says the same thing.

Meaningful graphics need a text alternative. Decorative graphics should be hidden from assistive technology so they do not add noise.

SVG in an <img> tag

Treat it like any other image:

<img src="logo.svg" alt="PNG to SVG Free home">   <!-- meaningful -->
<img src="swirl.svg" alt="">                  <!-- decorative -->

Some older screen reader and browser combinations did not announce SVG images correctly; adding role="img" to the <img> element is a harmless safeguard.

Inline SVG: meaningful

<svg role="img" aria-labelledby="chart-title chart-desc" viewBox="0 0 400 200">
  <title id="chart-title">Monthly conversions</title>
  <desc id="chart-desc">Conversions rose from 1,200 in January to 3,400 in June.</desc>
  ...
</svg>
  • role="img" tells assistive technology to treat the SVG as a single image rather than a group of shapes.
  • <title> provides a short name; <desc> adds a longer description.
  • aria-labelledby pointing to both makes support consistent across browsers.

For a simple icon, aria-label is enough: <svg role="img" aria-label="Warning">.

Inline SVG: decorative

<svg aria-hidden="true" focusable="false" ...>

aria-hidden removes it from the accessibility tree. focusable="false" prevents an old Internet Explorer behaviour where SVGs received keyboard focus; it is harmless in modern browsers.

Icon-only buttons and links

The most common accessibility bug: a button containing only an SVG icon and no text. Label the button, not the icon:

<button aria-label="Close dialog">
  <svg aria-hidden="true" viewBox="0 0 24 24">...</svg>
</button>

Alternatively, include visually hidden text inside the button. Either way, the user hears "Close dialog, button".

Charts and complex diagrams

A title and one-sentence description cannot convey a detailed chart. Provide the underlying data as an HTML table nearby, or a text summary of key findings. This also helps users with cognitive disabilities and anyone skimming.

Colour and contrast

  • Icons and graphical elements that convey meaning should have a contrast ratio of at least 3:1 against their background, as recommended by WCAG.
  • Do not rely on colour alone — pair red/green status icons with distinct shapes or labels.
  • Support Windows High Contrast / forced-colours mode: icons using fill="currentColor" automatically follow the system text colour, while hard-coded colours may disappear.

Text inside SVG

Real <text> elements in inline SVG can be read by screen readers and translated by browser tools. Text converted to outlines (as in many logos and traced images) cannot, so always provide an equivalent label.

Motion

Animated SVGs should respect the prefers-reduced-motion setting, and anything that moves for more than five seconds should be pausable. See SVG Animation Basics for an example.

Quick checklist

  1. Meaningful SVG has an accessible name (alt, aria-label or title).
  2. Decorative SVG has alt="" or aria-hidden="true".
  3. Icon-only controls are labelled.
  4. Charts have a text or table alternative.
  5. Graphics meet 3:1 contrast and do not rely on colour alone.
  6. Animations respect reduced-motion preferences.

Summary

Accessible SVG comes down to one question — meaningful or decorative? — and a few attributes. Label what matters, hide what does not, and check contrast. Your graphics will then work for every visitor, including those who never see them.
