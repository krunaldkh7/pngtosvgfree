SVG Gradients, Patterns and Filters: A Practical Introduction

Flat colours are the backbone of SVG, but the format also supports gradients, repeating patterns and image filters such as blur and drop shadow. Used carefully, they add depth and polish while keeping files small and scalable.

Where these features live: <defs>

Gradients, patterns and filters are defined once inside a <defs> element, given an ID, and then referenced by shapes using url(#id). Nothing inside <defs> is drawn directly.

Linear gradients

<svg viewBox="0 0 200 100">
  <defs>
    <linearGradient id="brand" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0" stop-color="#3d4ef5"/>
      <stop offset="1" stop-color="#8b5cf6"/>
    </linearGradient>
  </defs>
  <rect width="200" height="100" rx="16" fill="url(#brand)"/>
</svg>
  • x1, y1, x2, y2 set the direction. 0 0 → 1 1 is diagonal from top-left to bottom-right; 0 0 → 1 0 is left to right.
  • Each <stop> sets a colour at a position from 0 to 1. Add more stops for multi-colour gradients.
  • stop-opacity fades a colour to transparent.

Radial gradients

<radialGradient id="glow" cx="0.5" cy="0.5" r="0.5">
  <stop offset="0" stop-color="#fff" stop-opacity="0.9"/>
  <stop offset="1" stop-color="#fff" stop-opacity="0"/>
</radialGradient>

Radial gradients radiate from a centre point — great for glows, highlights and spherical shading. fx and fy move the focal point for an off-centre highlight.

Patterns

<pattern id="dots" width="10" height="10" patternUnits="userSpaceOnUse">
  <circle cx="5" cy="5" r="1.5" fill="#8b5cf6"/>
</pattern>
<rect width="200" height="100" fill="url(#dots)"/>

A pattern defines a tile that repeats to fill a shape: dots, stripes, grids or tiny illustrations. Patterns stay crisp at any zoom, unlike repeating image textures.

Filters

Filters apply pixel-based effects to vector shapes. They are powerful but can be slow on large areas and are not supported by every tool that reads SVG.

Blur

<filter id="soft"><feGaussianBlur stdDeviation="4"/></filter>
<circle cx="50" cy="50" r="30" fill="#ec4899" filter="url(#soft)"/>

Drop shadow

<filter id="shadow" x="-20%" y="-20%" width="140%" height="140%">
  <feDropShadow dx="0" dy="4" stdDeviation="4" flood-color="#000" flood-opacity="0.25"/>
</filter>

The x, y, width, height attributes enlarge the filter region so the shadow is not clipped.

Compatibility considerations

  • Browsers support gradients, patterns and common filters well.
  • Cutting machines and laser software ignore gradients and filters — they only use shape outlines. Remove effects from cutting files.
  • Canva, Office and some apps may simplify or drop filters and complex gradients.
  • Print: filters are rasterised at export; set a high resolution when exporting PDFs.

Gradients and traced images

When you trace a PNG with our PNG to SVG converter, gradients in the original become bands of flat colour, because tracing produces solid regions. If you want a smooth gradient in the final SVG:

  1. Trace with enough colours to capture the shape.
  2. Open the SVG in a vector editor.
  3. Merge the banded shapes into one.
  4. Apply a real linear or radial gradient fill.

The result is smoother and smaller than dozens of colour bands. See How Many Colours Should You Use When Tracing?

Performance tips

  • Prefer gradients over filters where possible; they are cheap to render.
  • Keep blur radii and filter regions small.
  • Avoid animating filters on large elements.
  • Reuse definitions — one gradient can fill many shapes.

Summary

Define gradients, patterns and filters in <defs> and reference them by ID. Linear and radial gradients add depth cheaply, patterns create crisp textures, and filters provide blur and shadows at a performance cost. Remove effects from cutting files and check compatibility with the apps your SVG will be used in.
