Styling SVG with CSS: Colours, Hover Effects and Themes

One of the best things about SVG on the web is that it can be styled with the same CSS you use for the rest of your page. You can recolour icons on hover, adapt illustrations to dark mode and keep brand colours consistent from a single stylesheet. This guide covers the essentials.

First: the SVG must be inline (or a sprite)

CSS from your page can only reach SVG elements that are part of the page's DOM. That means inline <svg> code or <use> references to symbols. An SVG loaded with <img> or as a CSS background is treated as a separate image and cannot be restyled from outside. See 5 Ways to Add SVG to a Web Page for the trade-offs.

The key properties

SVG shapes use their own set of CSS properties:

  • fill — the colour inside a shape
  • stroke — the colour of a shape's outline
  • stroke-width — outline thickness
  • stroke-linecap and stroke-linejoin — the shape of line ends and corners
  • opacity, fill-opacity and stroke-opacity
.icon path { fill: #3d4ef5; }
.icon:hover path { fill: #8b5cf6; }

Presentation attributes vs CSS

SVG files often contain attributes such as fill="#000" directly on elements. These "presentation attributes" have the lowest priority, so any CSS rule targeting the element overrides them. Inline style="fill:#000" attributes, however, have high priority and will beat your stylesheet unless you use !important. When preparing SVGs for styling, removing inline styles makes life much easier.

currentColor: the most useful trick

Set fill="currentColor" (or stroke="currentColor") in the SVG, and the shape will use the CSS color of its parent element:

<button class="btn">
  <svg viewBox="0 0 24 24" width="18" height="18"><path fill="currentColor" d="..."/></svg>
  Download
</button>

.btn { color: #3d4ef5; }
.btn:hover { color: #fff; background: #3d4ef5; }

The icon now changes colour together with the text, with no extra rules.

Multi-colour icons with CSS variables

For icons with more than one colour, use custom properties:

<svg class="duo" viewBox="0 0 24 24">
  <circle cx="12" cy="12" r="10" fill="var(--bg, #e3e7ff)"/>
  <path d="..." fill="var(--fg, #3d4ef5)"/>
</svg>

.card:hover .duo { --bg: #3d4ef5; --fg: #fff; }

The values after the comma are fallbacks, so the icon still looks right if the variables are not set.

Dark mode

Combine variables with the prefers-color-scheme media query:

:root { --ink: #0f1020; --paper: #ffffff; }
@media (prefers-color-scheme: dark) {
  :root { --ink: #f3f4fb; --paper: #0f1020; }
}
.illustration .line { stroke: var(--ink); }
.illustration .bg { fill: var(--paper); }

A single inline illustration now adapts to the user's system theme.

Sizing

An SVG with a viewBox scales to whatever width and height you give it with CSS. To make an icon match the surrounding text size, use em units:

.inline-icon { width: 1em; height: 1em; vertical-align: -0.125em; }

Learn more about how scaling works in The SVG viewBox Explained.

Strokes that do not scale

When you scale an SVG, stroke widths scale too. For diagrams or line icons that should keep a constant line thickness at any size, add vector-effect: non-scaling-stroke to the shapes.

Transitions and hover effects

Most SVG properties can be animated with CSS transitions:

.icon path { transition: fill .2s ease, transform .2s ease; transform-origin: center; transform-box: fill-box; }
.icon:hover path { fill: #ec4899; transform: scale(1.1); }

The transform-box: fill-box line makes transforms use the shape's own bounding box, which is usually what you want.

Preparing traced SVGs for styling

SVGs created with our PNG to SVG converter use plain fill attributes, so they are easy to restyle. Open the file, give the paths you want to control a class (for example class="brand"), and target that class in your CSS.

Summary

Inline your SVG, use fill and stroke, rely on currentColor for single-colour icons and CSS variables for multi-colour ones, and remove inline styles that block your stylesheet. With those basics you can theme an entire icon set from a few lines of CSS.
