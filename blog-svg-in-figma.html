Working with SVG in Figma: Import, Edit and Export

Figma is one of the most popular tools for interface and graphic design, and SVG is its natural partner. Icons, logos and illustrations move between Figma, code and other tools as SVG. Here is how to work with them smoothly.

Importing SVG files

There are three ways to bring an SVG into Figma:

  • Drag and drop the .svg file onto the canvas.
  • File → Place image (Shift+Ctrl/Cmd+K) and choose the file.
  • Paste SVG code: copy the code from a text editor or website and paste it straight onto the canvas. Figma converts it into editable layers.

Unlike PNG or JPG, which become image fills, an imported SVG becomes real vector layers you can edit.

Understanding the imported layers

Figma usually wraps an SVG in a frame named after the file, containing groups and vector layers. Traced SVGs may contain dozens or hundreds of vector layers, one per colour region. Tips:

  • Hold Ctrl/Cmd and click to select a layer deep inside groups.
  • Use Select matching layers (Alt+Ctrl/Cmd+A) to select all layers similar to the current one.
  • Flatten (Ctrl/Cmd+E) many shapes into one vector when you no longer need them separate — useful for single-colour icons.

Recolouring

The fastest method is the Selection colors section in the right panel. Select the whole imported frame, and Figma lists every colour used inside it. Change a colour there and every layer using it updates at once — perfect for traced logos that use a handful of colours across many shapes.

For a design system, replace those colours with colour styles or variables so the icon follows your theme.

Editing shapes

Double-click a vector layer (or press Enter) to enter vector edit mode. You can move points, bend curves with handles, add points with the pen tool and delete points. Boolean operations — Union, Subtract, Intersect and Exclude — in the toolbar combine shapes non-destructively.

Building icon components

  1. Place each icon in a square frame (for example 24 × 24) with consistent padding.
  2. Flatten the icon shapes into a single vector if it is single-colour.
  3. Set constraints to Scale so the icon resizes proportionally.
  4. Create a component (Ctrl/Cmd+Alt+K) and apply a colour style to the fill.
  5. Publish to your team library.

This keeps icons consistent, easy to swap and easy to export.

Exporting SVG

Select a layer or frame, click + in the Export section of the right panel, choose SVG and export. Useful options in the export settings include:

  • Include "id" attribute — adds layer names as IDs, helpful for developers but adds bytes.
  • Outline text — converts text to paths so it looks right without the font. Usually on for logos and icons.
  • Simplify stroke — merges strokes where possible for cleaner output.

You can also right-click a layer and choose Copy as → Copy as SVG to paste code directly into your project.

Common quirks

  • Strokes become outlines: some imported SVGs convert strokes to filled shapes. If you need editable strokes, rebuild those paths with Figma's pen tool.
  • Masks and clip paths may import as mask groups; check the layer order if parts disappear.
  • Filters and some gradients may not import exactly. Simplify complex effects before importing.
  • Exported icons include a background rectangle: remove the frame's fill before exporting.

Bringing raster logos into Figma as vectors

If you only have a PNG or JPG of a logo, Figma will treat it as an image. Convert it first with our PNG to SVG converter, then drag the SVG into Figma. You will be able to recolour it with Selection colors and resize it without blur.

Summary

Import SVGs by drag-and-drop or paste, use Selection colors to recolour quickly, turn icons into components with consistent frames, and export with outlined text. With these habits, Figma becomes a smooth bridge between your vector assets and your code.
