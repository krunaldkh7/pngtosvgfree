How to Create and Add an SVG Favicon to Your Website

The favicon is the tiny icon in the browser tab, bookmarks and history. For years it meant juggling a pile of PNG sizes and an old-fashioned .ico file. Modern browsers now support SVG favicons, which means one small file that looks sharp on every screen density — and can even switch colours in dark mode.

Why use an SVG favicon?

  • Always sharp — no blurry icon on high-resolution displays.
  • One file instead of many PNG sizes for desktop tabs.
  • Tiny — a simple icon is often under 1 KB.
  • Dark-mode aware — CSS media queries inside the SVG can change its colours.

Chrome, Edge, Firefox and Opera support SVG favicons. Safari has historically had limited support, which is why a PNG fallback is still recommended.

Step 1: Design for tiny sizes

A favicon is usually displayed at 16 × 16 or 32 × 32 pixels. Detail that looks great in your full logo becomes mush at that size.

  • Use a simplified mark or a single letter rather than the full logo with text.
  • Stick to one to three bold colours.
  • Use thick shapes and avoid thin lines.
  • Design on a square canvas, for example viewBox="0 0 64 64".
  • Consider a coloured rounded square behind the mark so it stays visible on both light and dark tab bars.

Only have your logo as PNG? Trace it with our PNG to SVG converter using a low colour count, then simplify it in a vector editor.

Step 2: Optimise the file

Remove metadata and unnecessary precision with a tool such as SVGO. Make sure the root element has a viewBox and an xmlns="http://www.w3.org/2000/svg" attribute — the namespace is required when the SVG is loaded as a standalone file.

Step 3: Add it to your HTML

<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
  • Browsers that support SVG favicons use the first line.
  • Others fall back to the 32 × 32 PNG.
  • iOS uses the 180 × 180 apple-touch-icon PNG when someone adds your site to their home screen.

You can create the PNG versions from your SVG with our SVG to PNG converter using the Width option.

Many sites also keep a favicon.ico in the site root, because some tools and older browsers request it automatically.

Step 4 (optional): Dark-mode favicon

Because an SVG favicon is a real SVG, it can contain a <style> block:

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <style>
    path { fill: #0f1020; }
    @media (prefers-color-scheme: dark) { path { fill: #ffffff; } }
  </style>
  <path d="..."/>
</svg>

A dark icon on a dark browser tab is invisible; this switches it to white when the user's system is in dark mode. Browser support for this behaviour varies, so a mark on a coloured background is the most reliable option.

Step 5: Add a web app manifest (for installable sites)

If your site can be installed as an app, add larger PNG icons (192 × 192 and 512 × 512) to a manifest.webmanifest file. Android and desktop app launchers use those rather than the favicon.

Troubleshooting

  • The old icon still shows: browsers cache favicons aggressively. Hard-refresh, open a private window, or add a version query such as favicon.svg?v=2.
  • The icon is blank: check the xmlns attribute and that the server sends the image/svg+xml content type.
  • It looks blurry or cropped: make sure the viewBox is square and the artwork fills it with a little padding.

Summary

Design a bold, simple, square mark, export it as an optimised SVG, link it with rel="icon", and keep PNG fallbacks for Safari and home-screen icons. You get a crisp tab icon on every display with a file smaller than this paragraph.
